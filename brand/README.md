# MLsuite identity

Original mark copied unchanged from `eshkra/src/assets/marks/mlsuite.png`
(960 × 512), the highest-resolution source of this mark. The PNG retains its
original resolution and embedded provenance. `frontend/public/mlsuite.png` is the
same file; `frontend/public/favicon.png` is this mark resized to 256 pixels wide
and centered on a transparent 256 × 256 square.

Outlined wordmarks use Mona Sans from the family's self-hosted Latin subset: ML at
weight 800 and width 125%, suite at weight 300 and width 100%, matching MLbundle,
MLschema and MLform glyph for glyph. Font license: SIL OFL 1.1, included alongside
these assets. Wordmarks are SVG paths so GitHub needs no fonts.
`wordmark-light.svg` is graphite `#0b0b10` for light backgrounds;
`wordmark-dark.svg` is `#f4f4f6` for dark ones.

Use orange `#f07a1e`, the MLsuite hue on eshkra.dev, with graphite and neutral
backgrounds; README badges use `#b85000`, a darker shade of the same hue, behind
white text. Use MLsuite for the brand lockup and in prose; keep `mlsuite`
lowercase in repository, service and image names, commands and URLs. The in-app
themes are user choices and do not change the brand.

README image URLs are absolute repository URLs, so they resolve once these assets
reach `main`.
