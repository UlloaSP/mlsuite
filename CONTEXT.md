# MLSuite

MLSuite organizes machine-learning work and access inside organizations.

## Access control

**Role definition**:
An organization's named permission set assigned to memberships and invitations.
_Avoid_: Role, legacy role

**Legacy role**:
A fixed historical access label retained only while existing records migrate to role definitions.
_Avoid_: Permission set, custom role

**Active membership**:
An organization membership that grants access and may participate in current organization work.
Pending and removed memberships are historical records and grant no access.
_Avoid_: Membership, valid membership
