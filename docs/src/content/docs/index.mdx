This is the manual for MLsuite, an open-source platform for running machine-learning models
through generated forms and collecting human feedback on their results. It covers every option
of the web application, the client API that outside software calls, and how to run your own
instance. The screens come from the public instance at
[mlsuite.irlab.org](https://mlsuite.irlab.org/), where anyone can create an account and try it.

:::caution[Early software]
MLsuite is pre-1.0. Expect rough edges and breaking changes. Model bundles run unsandboxed in the
runtime, so only members you trust should be able to upload them; see the
[security policy](/security/).
:::

## How it fits together

MLsuite keeps the whole loop in one place, and keeps every result tied to what produced it:

| Step | Where | What is kept |
| --- | --- | --- |
| Upload a trained model | [Models](/models/upload/) | The `.mlbundle` file, its SHA-256 and what the bundle says about the model. |
| Describe its inputs and outputs | [Schemas](/schemas/overview/) | Immutable, numbered snapshots of the form and its model bindings. |
| Run it | [Predict](/predictions/run/) | Each saved run, with its inputs, every model's result and the exact snapshot. |
| Review the results | [Review](/feedback/reviews/) | Each reviewer's answers, per inference and per report. |
| Use the data | [Inferences](/predictions/inferences/) and [export](/predictions/export/) | A filterable table and a CSV of everything above. |

Models come from [MLbundle](https://docs.mlbundle.eshkra.dev/), which packages scikit-learn,
XGBoost, CatBoost and ONNX models without pickle. Forms are drawn by
[MLform](https://docs.mlform.eshkra.dev/). Both are part of [eshkra](https://eshkra.dev), like
MLsuite. MLsuite is MIT licensed; read the source on
[GitHub](https://github.com/UlloaSP/mlsuite).
