## What MLsuite accepts

MLsuite accepts trained models only as `.mlbundle` files exported with
[MLbundle](https://docs.mlbundle.eshkra.dev/). A bundle holds the model in its native,
pickle-free format together with a manifest and a schema of its inputs and outputs. MLsuite never
loads pickle or joblib files.

| | Supported |
| --- | --- |
| Libraries | scikit-learn, XGBoost, CatBoost, ONNX |
| Tasks | Tabular classification and regression |
| Bundles | Written with the MLbundle version the runtime pins in `backend/pyproject.toml` (0.2.1 at the time of writing) |
| scikit-learn | The version the runtime pins (1.9.1 at the time of writing); a bundle from another version is refused |

The bundle's schema is used as it comes: export with `training_data=` to infer the form fields
from the training frame, otherwise every feature becomes a number field. Fields map to the model's
own feature names, or to positions `0`, `1`, … for a model without names. One-hot columns are
grouped into a single choice using the separator the bundle was exported with. Each model output
gets its own report.

:::caution[Trusted uploaders only]
Model parsers and inference run unsandboxed in the runtime. Give upload permissions only to people
you trust; see the [security policy](/security/).
:::

## Upload

<Capture
  name="model-upload"
  alt="The Create model page with one bundle checked and ready, its name field, Save and Remove buttons and a session summary."
/>

1. Open **Models** and choose **New model** (needs **Create models**).
2. Drop one or more `.mlbundle` files, or choose **Add files**. A file that is not a bundle, or one
   already in the list, is not added and a message says so.
3. Check the name of each model. It defaults to the file name in title case and must be unique in
   the organization; a card without a name says so, and **Save all** names the bundles it left
   unsaved for that reason.
4. Choose **Save** on a card, or **Save all** to save every bundle in turn. Each file is uploaded
   once, when it is saved: the runtime reads it then, and a file it cannot load stays in the list
   with the reason, such as "Cannot load bundle: …". When all are saved, MLsuite opens the models
   list.

A bundle can be at most 512 MB, the largest archive MLbundle reads; a larger file is refused with
`413`. Models that a [public bookmark](/publishing/publish/) or an [API client](/api/clients/) runs
are limited to 50 MB by default.

## The models list

<Capture
  name="models"
  alt="The Models list with three demo models, each showing its kind and algorithm, author, update time, field and report counts."
/>

Search by name, file or algorithm; filter **Active**, **Archived** or **All**; sort by **Latest
updated**, **Name** or **Algorithm**. Each row shows the kind and algorithm, who changed it last,
and how many fields and reports its bundle schema has.

## The model page

<Capture
  name="model-detail"
  alt="A model page: algorithm, predicted classes, bundle facts and a feature importance chart."
/>

The header shows the kind, library, input and output counts, the file and its size. **New schema**
starts a schema from this model. The tabs are:

| Tab | Shows |
| --- | --- |
| Overview | The algorithm or pipeline steps, what it predicts (classes, or "A number"), bundle facts and feature importance when the model's structure provides it. |
| Inputs | Every form field: its kind, which feature columns it feeds, the training type and whether it is required. |
| Outputs | Each report, its kind, output position, target and classes. |
| Parameters | The model's hyperparameters, grouped by pipeline step and searchable. |
| Provenance | The stored file and its SHA-256, the bundle id and format, each member of the archive with its hash, the training environment (Python, system, package versions) and the author's notes. |

The training environment is what the exporter declared; MLsuite does not check it against the
model.

## Rename, duplicate, archive, delete

The actions of each row in the models list:

| Action | Effect |
| --- | --- |
| Edit | Rename the model (needs **Edit models**). |
| Duplicate | Copy it under a new name (needs **Create models**). |
| Archive | Hide it from the active list. Archived models stay listed under **Archived**, open with an **Archived** badge, cannot be chosen for new schemas, and keep running in the schemas that already bind them. **Restore** returns an archived model to the active list. |
| Delete | Remove it for good (needs **Delete models**). Refused while any schema snapshot or inference uses the model: archive it instead. |

If someone else changed the model since you loaded the page, the action is refused with "Model
changed since it was loaded; refresh and retry". Reload and try again.
